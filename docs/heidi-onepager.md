| Pain | Today's reality |
|---|---|
| **1. Discovery** | 960,000 practitioners Google "CPD courses" and land on random providers. No way to verify legitimacy or college accreditation. |

| **3. Audit nightmare** | CPD records scattered across Medcast, RACGP webinars, conferences, independents. Manual tracking. AHPRA audit = scramble through email confirmations. |

**Today's clinician journey:**
```
Need CPD → Google → Random provider → "Is this legit?" → Complete →
Save email confirmation → Repeat 3-5× → AHPRA audit → Reconstruct from scratch
```
