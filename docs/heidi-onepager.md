## The Problem — Three pain points killing Australian clinicians

**1. Discovery problem.** ~650,000 AHPRA-registered practitioners need 20-50 CPD hours per year. Most Google "CPD courses Australia" and land on random providers with no way to verify legitimacy or accreditation quality.

**2. Quality problem.** No central vetting. Course quality varies wildly. Some courses don't actually meet RACGP / ACRRM / college standards despite claiming to. Clinicians waste hours on garbage that doesn't count.

**3. Audit nightmare.** CPD hours scattered across Medcast, RACGP webinars, conferences, independent providers. Manual tracking in spreadsheets and email confirmations. When AHPRA audits, clinicians spend hours reconstructing their record.

**Today's clinician CPD journey:**
```
Need CPD → Google → Random provider → "Is this legit?" → Complete →
Save email confirmation → Repeat 3-5× across providers →
AHPRA audit → Hours of record reconstruction → Hope nothing is missing
```

---

## The Solution — Heidi Clinical Education Platform

**1. Trusted curation.** Heidi vets every provider before listing. If it's on Heidi, it's been quality-checked against RACGP / ACRRM / AHPRA standards.

**2. Auto-tracking.** Every completion logged automatically. One dashboard, every provider, every hour.

**3. Audit-ready export.** One-click PDF transcript. Direct integration with RACGP and ACRRM CPD Homes (roadmap).

**Heidi-platform journey:**
```
Open Heidi → Curated CPD library → One-click purchase → Complete →
Auto-logged + cert issued → AHPRA audits → Click "Export" → Done
```

This is **audit insurance**, not just convenience.
